# Pharma Radar 人工标注规范

版本：1.1；日期：2026-10-06。用途：教学、编辑判断和后续精选校准。此规范不改变生产评分提示词、五维权重、信源门槛或模型预算。

配套材料：[代表性判断卡](annotation-cards-2026-10-06.md)、[临床与监管补充卡](annotation-cards-additional-2026-10-06.md)、[空白标注表](annotation-worksheet.csv)、[期刊指标说明](journal-metrics.md)、[指标登记表](../industry/journal-metrics.json)、[当前精选流程](selection.md)。

## 1. 先判断材料，再判断阅读价值

推荐表示“值得目标读者阅读”，不是论文质量百分比、结论为真的概率或人体治疗有效性的认证。期刊影响因子也不代表单篇论文的可信度。

助手负责核对文献身份、材料范围、研究对象、方法、结果和指标来源，给出可以复查的事实说明。运营者判断读者能从中学到什么、是否值得继续阅读或收藏；无法判断时可填“待核对”。专业方法问题需要进一步查阅材料或请领域研究者复核。

每张卡片必须区分：

- **来源事实**：可以在标明的摘要、正文、补充材料或出版商信息中核对。
- **编辑判断**：例如学习价值、推荐对象和对本站读者的相关性，注明理由。
- **待核对事项**：当前材料没有交代或尚未独立查证的问题。不能写成作者没有采取该设计。

未核对相关研究的比较背景时，不独立宣称“首次”“突破”或“优于现有方法”。

## 2. 分开记录四类问题

| 判断 | 需要回答的问题 | 不应混同的情况 |
|---|---|---|
| 收录边界 | 是否有明确药学关联？ | 农业用途不因属于天然产物就自动符合专题 |
| 内容准确 | 文献身份、数字、结论和阶段是否得到来源支持？ | 患者数据分析不等于临床试验；对接不等于 AI |
| 材料完整 | 当前材料是否足以说明研究对象、方法和结果？ | 摘要未报告随机化不等于研究没有随机化 |
| 推荐价值 | 对学生或研究者有什么具体阅读用途？ | 普通收录不等于研究不严谨或没有价值 |

发现关键事实错误，先记录并修正；修正前不作最终精选结论。材料不足且影响判断时，填“待核对”，不以低分代替未知。

推荐前至少检查：

1. 天然产物具有药学关联；AI 专题包含实质应用或药研工具，只有展望中的 AI 不构成依据。
2. 原始研究、综述、方法资源、评论、出版商简讯和预印本的类型与来源属性正确。
3. 核心结论、数字和证据阶段可追溯到本条实际获取的材料；缺失字段留空。
4. 原始研究或方法资源至少有对象、方法、结果；综述至少有对象和综述要点。仅标题或背景材料不进入自动研究精选。
5. 预印本显著标注，必须经过人工编辑审查才可精选。研究简讯使用自身 DOI、期刊和发表日期，不能继承被报道论文的身份。
6. 已正式撤稿的研究不作为正面研究推荐；撤稿、更正或质疑可单独作为研究诚信资讯收录。

发表日期按来源材料保存精度：仅日期不产生虚构时刻，未知不以本站收录时间代替。书目日期与来源时刻明显冲突时先按书目日期解释，避免晚收录或较新的 RSS 时间把旧论文变新；跨时区的日差单独注明，不拼接日期和时刻。原始来源字节、已有规范化时间和编辑修正分别留痕。

## 3. 最简单的一次评判

先看卡片的文献信息、已知事实和材料范围，再回答下面四个问题。第一次练习可查看助手建议，之后独立标注应先隐藏建议。

- 读者具体能理解或完成什么？例如学习疼痛行为测量、了解某种药理机制的实验设计、查找一类方法。
- 是否值得读原文或收藏？只根据现有材料判断，不要求猜测全文。
- 更适合入门学生、有基础的学生、研究者，还是暂无法判断？
- 若不推荐，主要原因是材料不足、价值尚不明确、方向不符，还是事实需要修正？

将 [CSV 标注表](annotation-worksheet.csv) 另存为私人副本，再填“判定、推荐对象、阅读用途、主要理由、待核对问题、事实问题、把握程度、评判者、评判日期、是否先看到助手建议”。不必先填写数字评分；评判者信息、未公开原始材料及填写后的表格不提交到公开仓库。

| 判定 | 含义 |
|---|---|
| 精选：研究价值 | 主要推荐研究问题、设计、验证或可解释结果 |
| 精选：学习价值 | 主要推荐知识框架、方法训练、代码数据或可复用流程 |
| 精选：研究与学习价值 | 两类理由均可具体说明 |
| 资讯精选 | 监管批准、政策或产业进展值得关注，推荐理由是已确认事件及其影响，不是论文研究质量 |
| 普通收录 | 符合方向，现有材料未显示足够的推荐优先级 |
| 待核对 | 事实、材料或价值判断还有影响结论的未知项 |
| 不符合收录边界 | 明确指出与已确认药学边界不符的理由 |

把握程度可填“高／中／低”，表示对这次编辑决定的把握，不表示研究为真的概率。没有资料支撑时，不为凑齐表格作猜测。

监管和产业条目另检查事件是否发生、适用范围、生效或批准日期、监管条件及消息出处。官方批准公告可证明批准动作，不能补成完整临床研究评价；这类资讯不硬套研究 / 学习标签，不以 JIF 打分，也不混入论文研究质量盲测。

## 4. 可选的细化评价草案

下表是教学与讨论用的六项编辑草案，尚未经过正式校准。它与线上五维事件注意力评分不同；不直接写回模型分数，不自动精选。

| 维度 | 草案满分 | 判断内容 |
|---|---:|---|
| 药学方向相关性 | 20 | 是否帮助理解药物发现、药理机制、制剂药代或临床转化 |
| 研究增量 | 20 | 能否指出相对于已有认识的增量；阴性结果、复现和方法改进也可有价值 |
| 证据与验证 | 25 | 设计是否匹配问题、对照和验证是否支持核心主张、结论是否越过材料范围 |
| 学习与复用价值 | 20 | 是否有清楚框架、可复用实验流程、代码数据或方法评价 |
| 时效性 | 5 | 按原始发表日期及当前相关程度判断；晚收录不会使旧研究变新 |
| 期刊传播参考 | 10 | 仅使用已核实、带年度的期刊指标及相关类别位置 |

前五项合计满分 90。已能判断的项目可使用 0–4 级：0=明确缺乏该价值，1=较弱，2=中等，3=较强，4=很强；换算为“级别 / 4 × 满分”。0 必须有否定依据；未知留空，不能填 0。

研究增量或证据与验证中的关键内容无法判读时，不给完整内容分或总分；只列已判断项目及未知事项。仅期刊项未知或不适用、其余项目均可判断时，可以单列内容分 / 90，不能补成一个看似完整的 / 100 分总分。人工推荐结论始终单独记录。

### 不同材料的检查重点

- **实验研究**：对象、对照、终点、效应及不确定性；摘要未交代样本量、随机化、盲法时记“当前材料未交代”。
- **AI / 计算方法**：训练与测试分离、比较基准、独立外部验证、代码数据。内部基准不等于独立验证；模型表现不等于候选药物有效。
- **综述**：整理的问题、证据来源、综合方式与争议边界。叙述性综述可有学习价值；不要冒称系统综述。其阶段标签表示涵盖证据，不表示本篇实施了试验。
- **临床研究**：设计、对照、主要终点、效应和安全性；统计显著不等于临床意义充分，未报告信息继续待核对。
- **出版商简讯**：区分简讯自身与被报道研究；介绍某种进展不自动提供完整方法、结果或疗效证据。

研究阶段是分类信息，不是质量分数。计算研究可有严谨外部验证，动物实验也可能缺少合适对照，不能按“计算 < 体外 < 动物 < 临床”机械加分。

## 5. 期刊指标的使用边界

登记期刊名、ISSN / eISSN、年度 JIF、JIF 数据年度、JCR 发布版本、类别及该类别排名 / 百分位 / 分区、来源链接和核对日期。JIF 数据年度与 JCR 发布版本分开记录；来源没有交代的字段保持未知。出版商页面的更新时间、版权年份或当前年份不能代替指标数据年度。

Clarivate / JCR 或出版商、学会官方页面可作为优先来源；未找到免费可核对资料时保留“未核实”。CiteScore、SJR、中科院分区不能改名当成 JIF 或 JCR 分区。具体登记状态见 [期刊指标说明](journal-metrics.md)。

期刊项 10 分的试行表仍是候选编辑政策，不是正在运行的评分规则：若相关类别 JIF 百分位已核实，可讨论 ≥90→10、≥75→8、≥50→6、≥25→4、<25→2；只有同年度、已核实 JCR 分区时，可暂讨论 Q1→8、Q2→6、Q3→4、Q4→2，并注明缺少精确百分位。正式采用前需要开发集和留出检验。

仅有 JIF 数值而没有可核对的相关类别位置，不填写期刊参考分。多个类别先按研究方向确定相关类别并保留全部类别，不挑最高值提高分数。预印本和非期刊监管资料记“不适用”；简讯只能引用自身刊载期刊的指标，且该指标不补足研究材料。

高 JIF 不能覆盖事实错误、材料不足、收录边界或未验证的实验阶段。此登记表当前不参与生产模型输入、五维计算或信源门槛。

## 6. 标签来源与样本划分

| 标签来源 | 用途 | 可否视作独立人类标签 |
|---|---|---|
| 助手受用户委托作出的编辑决定 | 内容编辑、教学和开发讨论 | 否 |
| 用户看过建议后同意或改判 | 有引导的讨论标签，保留原话与是否看过建议 | 否，不能用于未受引导的留出检验 |
| 用户或读者先独立判断，之后才看建议 | 独立人类标注，记录评判者、日期和原始决定 | 可以；仍需确认没有用于调规则 |
| 助手或模型自动生成 | 初步建议、比较或辅助核对 | 否 |

同意助手继续推进不等于给每篇独立标注。当前既有受托审核不能算成独立人类金标准。本轮 PR-01 至 PR-14 已含助手说明与建议，属于教学 / 开发样本，不进入留出集；CSV 留空不代表已经得到标签。

### 分阶段校准

1. **12–15 篇教学样本**：共同练习，将分歧拆成边界、准确性、完整性和推荐用途问题。
2. **约 40 篇开发集**：按专题、类型、证据阶段、材料完整度和正反难例分层，形成独立标签后用于改标准。
3. **另约 20 篇留出集**：在调规则前固定，不展示模型分数、本站是否精选或助手建议，不用来反复改提示词。中性事实与期刊指标保持和实际产品使用相同的信息范围。
4. **必要时扩到 100–200 篇**：40 + 20 是阶段检查，不足以证明广泛泛化；类别过少、分歧较大或要大改门槛时扩样。已曝光、已用于调规则的留出条目转开发集，另补新的留出样本。

按论文自身 DOI 和同一研究 / 事件分组后划分，避免同一论文不同来源、版本或相关简讯横跨开发与留出集。保留标签来源、标注材料版本、判断日期、分歧和修正记录。内容修复可以更新材料，但不能悄悄改写原始人类决定。

## 7. 评测与上线决定

人工表中的研究精选 / 学习精选可以映射为评测 select，普通收录或明确范围外可映射为 reject，同时保留原因类型。待核对不应直接当成 reject；先补材料，或暂列 either 并从决定性指标排除。资讯精选可在独立的监管 / 产业资讯筛选评测中映射为 select，按内容类型分层报告，不混入论文研究质量判断。详见 [现有评测格式](selection.md)。

评分评测只检验模型筛选与人工推荐是否一致，不替代文献身份、数字依据、阶段标签或全文质量复核。分开报告：

- 精选查准率、查全率、错误案例和各分层覆盖；同时给出样本数和错误条数。
- 边界误收、事实错误、材料不足和推荐偏好分歧。
- 助手受托标签、受引导用户标签与独立人类标签的数量；留出集单独报告。
- 被排除、请求失败或材料变化的样本，不混入成功准确率。

先修事实和标准，再讨论门槛；不能为达到精选比例改标签。生产仍沿用七类内容、五维加权、两次评分及信源门槛。六项人工草案和期刊参考仅在用户独立标签形成、开发调整和留出检验后，才决定是否以及如何映射到现有实现。
