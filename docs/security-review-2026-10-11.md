# Pharma Radar 安全与使用审查补充（2026-10-11）

本轮补齐前次审查留下的技术检查和可自主完成的修复。保留匿名阅读、旧资料入口、收藏存储格式、RSS、公开 API 与 `pharma_radar` MCP 前缀；免费部署、信源间隔和模型预算保持不变。本记录不覆盖真实读者试用和独立人工内容标注。

## 已证实的问题与修复

| 问题 | 修复及验证范围 |
|---|---|
| 飞书成功上传截图后，原私有文件删除失败可能丢失清理键和存储账目 | 增量迁移 0049 在既有反馈表保存待清理原文件键。成功上传与待清理键同一次写入；删除失败不丢弃可复用图片、不宣称删除完成，继续记账并由维护任务重试。转发关闭时也清理；管理员删除先确认原文件删除成功。五类真实数据库与受控 HTTP 桩回归通过。 |
| 来源撤销权限后，旧公开投影仍可返回资料或全文 | 所有相关读取按当前来源参与模式检查。全文同时受当前站内许可约束，RSS 全文另需当前转载许可；正文检索、Markdown、X 正文及引用/译文使用同一边界。独立来源继续可见。 |
| 撤权与恢复之间的同步状态可能永久漏项 | 来源参与模式实际变更时在同事务更新同步 epoch；每次同步实时读取。旧游标沿用既有 `409 snapshot_required`，分页绑定失效，不制造无对应恢复事件的临时 remove。回归覆盖 worker 重发布前隔离又恢复、相同投影无需新 upsert 的情况。 |
| 暖缓存或旧 ETag 可延迟反映来源许可 | 仅来源相关公开请求在使用进程缓存/ETag 前执行一次轻量权限聚合查询。跨进程变更清理专题、简报索引、热点、统计、MCP、资料计数和 sitemap 等缓存；旧异步刷新不能回填新代缓存，条件分享图也检查权限。数据库错误返回既有 503/no-store，不继续使用旧许可缓存。 |
| 浏览器拒绝本地存储时，收藏/取消/已读操作仍显示成功 | 写入失败保留原可靠状态并明确提示，不播放成功动画。覆盖 QuotaExceededError、SecurityError、不可写导入及部分导入失败；旧存储键与 version:1 不变。 |
| 分享图弹窗焦点留在背景，隐藏回顶按钮仍进入键盘顺序 | 弹窗初始焦点、实时 Tab/Shift+Tab 循环、Escape、关闭后焦点恢复均已复测；隐藏回顶按钮禁用并退出 Tab 顺序。 |
| 合法不同时区收藏日期按字符串排序、同文件导入难以重试 | 按实际时间戳排序，保留原日期格式；选择后重置 file input，允许同文件重试。 |
| 手机操作区域、主题键盘操作、长标题和深色提示可读性不足 | 常用收藏/移除/导入导出/海报操作、更多支持链接和主题按钮至少 44px；主题使用单一 Tab 入口及箭头/Home/End；长收藏标题可折行。深色错误字色对当前背景从约 4.32:1 调整到约 5.45:1。后台登录新增主区域和一级标题。 |

## 准确保留的边界

1. 许可校验约束新源站读取，不能抹除已经下载、截图或仍在有效期内的浏览器/中间缓存。既有 HTTP TTL/SWR 保留；部分 RSS/快照可缓存 300 秒并允许 SWR 900 秒，分享图及简报分享图更长。不得宣称所有客户端立即撤回。
2. 热点仍关联隔离来源时会保守隐藏整条旧热点，需整理相关关联或恢复来源后才恢复；不能保证仅重算排名即可恢复。
3. 0049 无法恢复此前已丢失且回执已清除的原文件键。当前生产桶无对象，没有发现现存遗留文件；不能据空桶证明真实删除失败分支在线可靠。飞书继续关闭，本轮全部转发/存储故障验证均使用受控桩，不发送真实消息。
4. 每个来源相关公开 API 请求增加一次轻量数据库查询，未增加模型调用或收费资源；数据库故障仍可能导致暂时不可用。
5. Render 免费休眠首次打开可能等待，定时执行与信源到期不保证精确到点。独立调度过夜实际派发 CPU 6.704–9.299ms 已完成验收，最高余量仍有限；不能外推永久保证。模型预算等待与平台触发延迟分开记录。
6. 真实手机/读屏工具、独立读者 T01–T10 试用、人工精选样本和导读深度校准未由技术自测代填。当前关闭的旧 X 菜单交互在启用前应补真实键盘检查。
7. 未实施高流量攻击、完整第三方管理面审计或全历史内容逐篇审查。此次通过的是有界技术审查，不是零风险认证。
