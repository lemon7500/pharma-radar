# Pharma Radar 阅读界面更新（2026-10-01）

本轮按用户确认的 AIHOT 风格草案实现：桌面侧栏、紧凑页头、原始发表时间线、日期导航；继续使用 Pharma Radar 品牌和药学组合分类。

## 阅读页面

- 导读：首页以全部资料／编辑精选切换，按原始发表日期从新到旧分组，显示星期、**本页**条数和可折叠时间线。两个重点专题可组合选择。有真实公开热点数据时才展示近期关注。
- 资料库：桌面常驻组合筛选；手机折叠面板。支持发表日期范围、发表最新／最早、搜索相关度、分页与可分享的完整查询链接。
- 专题：默认发表时间线，可切换研究环节视图；切换环节或视图保留日期范围。
- 详情：标题附近显示发表日期、来源属性、材料范围和原文操作。研究信息缺失时合并提示；目录、文献元数据和全部收录来源保留。长作者列表可展开。
- 简报：保留刊物结构和引用，显示实际资料窗口、编制时间与版本。
- 阅读清单：保留旧 `aihot-*` 浏览器存储键和导入导出格式，新增可选发表日期字段、收藏／发表排序和未读筛选。撤回条目的本地收藏继续保留。

日期左栏：仅有日期时两行 `10/01`、`发表`；有可靠时刻时三行 `10/01`、`09:35`、`发表`。准确时刻统一显示 UTC+08:00。日期精度与本站收录时间放在展开的文献信息中。

## 时间语义与兼容

读者页使用独立的 `publication` 排序：优先来源文献元数据中的有效发表日期，其次有效原始 `publishedAt`，未知日期排在最后。不以本站收录时间补充发表日期。日期范围在数据库中与排序、检索一起执行，然后分页，避免客户端仅重排当前页。

历史日期可能被保存为 UTC 或 UTC+8 午夜；缺少明确精度标识时，保守地只显示日期。来源日期、非法日期和未来日期不会被展示成虚构的准确时刻。来源只提供发表日期的元数据也会保留。

`timelineAt` 的既有含义、v1、RSS、MCP、文章／专题旧链接和发布门禁不变。此次没有数据库迁移，不调整信源、精选门槛、模型预算或旧稿整理策略。网页访问继续不调用模型。

## 验证

自动检查涵盖日期精度、UTC+8 跨日、未来／非法日期、晚收录旧论文、范围筛选、跨页稳定排序、相关度时间并列，以及旧时间轴兼容。公开来源数量从统一公开投影读取，重复 DOI 的其他信源可从详情进入。

本地完成类型检查、生产构建、205 个后端测试（另 6 项平台相关测试留给 Linux CI）、16 个网页测试、全部页面／公开 API／RSS／MCP 冒烟检查。新增公开元数据之后再次通过 35 项相关回归。使用 gstack `/browse` 检查了 67 种页面与屏幕／主题组合，无横向溢出；17 项交互检查覆盖时间换行、折叠、条件保留、分页、详情返回和旧收藏。

所有排版样本与浏览器检查截图只保存在被忽略的 `.data`，不会部署为真实研究内容。上线仍由现有 GitHub Actions 检查及 Render 服务完成。
