# Pharma Radar 安全与使用审查（2026-10-08）

本次完成代码修复、隔离复现和本地回归。发布后的验证结果另记于交接文件；不把本地通过当作线上已经生效。

## 审查范围与方法

按访问权限、防滥用、数据与密钥、读者流程、运行可靠性和发布复测逐项检查。线上只读取页面、权限及汇总状态；错误登录、大请求、损坏图片、慢上传、超时补偿均使用本机独立数据库、假凭据与模拟服务。不提交真实访客反馈、不清除合法旧反馈、不提高模型调用预算。

## 已证实问题与修复

| 问题 | 处理与验证 |
|---|---|
| 换浏览器可绕过反馈限流 | 网络地址的带密钥摘要独立于浏览器类别；数据库原子计数在重启和不同 API 实例间保留。新封禁覆盖同一地址全部浏览器类别。 |
| 上传总量与并发缺少限制 | 每地址 5 次/分钟、20 次/北京时间自然日，全站 100 次/日；截图尝试写入 50 MiB/日，保留存储 100 MiB；全局 2 个请求、单地址 1 个，接收请求体最多 30 秒。既有未知大小截图按原 8 MiB 上限保守计入。 |
| 只验证图片声明类型 | 检查真实格式并完整解码，限制单帧、20 MP、边长 8192、输入和处理后大小 5 MiB；重编码去除图片元数据。当前表单接受 PNG/JPEG/WebP，旧 JSON 客户端的静态 GIF 转为 PNG。 |
| 上传失败与不确定结果可能残留文件 | 上传前记账；远端失败保留预留，到 120 秒租约结束后补偿删除。成功提交不会被失败补偿删除；缺少远端配置时不误报删除成功。小时采集任务执行清理并记录 `cleanupPending`。 |
| 失败重试可重复提交、发送期间编辑会丢稿 | 表单发送期间锁定；30 秒客户端超时保留草稿；同一份内容重试沿用提交编号，7 天回执避免重复入库和重复上传。只有合法成功回执才清稿。 |
| 单访客输错密码耗尽全站 15 分钟额度 | 单地址 10 次/15 分钟；已拒绝请求不消耗全局额度。分布式突发采用固定 30 秒冷却，拒绝请求不会延长冷却；状态容量有上限。 |
| 密码修改后旧会话仍有效 | 会话绑定当前凭据的带密钥指纹；修改密码、会话密钥或飞书凭据后，旧会话无效。飞书会话同时重查允许名单。新增带会话和 CSRF 保护的“退出所有设备”，保留审计。 |
| 手机后台无可见退出、损坏 Cookie 导致错误 | 手机和桌面均可退出；畸形 Cookie 安全忽略。迁移前旧会话需要重新登录一次。 |
| MCP 实际请求体超过声明上限 | 在解析前设置 256 KiB 上限；超限返回 413，正常初始化和原工具前缀保持兼容。 |
| 收藏核验行为与隐私说明不一致 | 明确打开清单会发送资料编号核验公开状态；不发送收藏时间、已读记录或草稿，应用不持久保存该查询；托管网络日志可能记录请求。导出仅包含收藏、已读记录与主题偏好。 |
| 500 条长收藏编号会超过 HTTP 请求行限制 | 每批最多 50 条，最多两批并行；有超时和离页取消。失败批次保持未确认，不错误标记资料撤回。保留已有收藏格式与接口。 |
| 静态目录前缀判断可接受相邻同前缀路径 | 使用解析后的相对路径验证目录边界；编码穿越不能读出相邻测试文件，正常静态资源继续可用。 |
| 外部抓取重定向可能携带认证资料 | 跨域删除认证头；拒绝带密钥查询、正文重放及认证 HTTPS 降级；同域正常重定向保留兼容行为。 |
| 运行页面积压计数易误解 | 改为“未整理或版本待更新”，明确不含周期性来源复查、不等于本轮可执行量，各项统计可重叠。调度与调用预算保持原样。 |

## 数据、依赖与公开范围

- 发布前云端 63 张业务表全部启用 RLS，匿名及普通登录角色无表读写权限；截图和备份桶均私有。增量迁移新增两张私有防滥用表，发布后需再次核对。
- 仓库历史 55 次提交、1,132 个文本对象与新生产构建文本产物的指定密钥/私钥/认证地址模式筛查未发现候选；待发布文件及最终构建另经当前实际密钥值核验，无匹配。云端任务与模型错误记录的同类模式筛查也未发现候选。这是定向筛查，不是对所有可能密钥形式的保证。
- 升级图片处理依赖至 Sharp 0.35.5、source-map-js 至 1.2.2、开发用 MCP 客户端至 2.3.1。完整依赖审查含开发依赖为 0 条已知公告。公告：[Sharp](https://github.com/advisories/GHSA-wq5f-xc86-pv6w)、[source-map-js](https://github.com/advisories/GHSA-68fv-2mgg-jv7q)、[MCP 客户端](https://github.com/advisories/GHSA-6qxp-vccf-f47h)。没有据此认定本站已被利用。
- 公开读取层继续排除私有依据片段、原始载荷及模型回执。页面隐藏 AI 分数；旧公开 API 和 MCP 的既有 `score` 字段保留兼容，不用于向读者宣称研究质量。
- 页面、静态文件和 API 增加禁止嵌入、类型嗅探防护、引用来源策略、权限策略、HTTPS HSTS 与 CSP。现有路由和主题功能仍需内联脚本/样式；此 CSP 是加固，不是严格的脚本防注入保证。既有内容清洗与 URL 防护继续作为主要控制。

## 尚未验证及使用约束

1. 免费托管仍可能休眠，GitHub 定时任务不保证精确到点；不得把计划采集时间当作实际成功时间。发布后需核对来源最近成功时间和任务运行状态。
2. 清理随小时任务执行；任务延迟或云端存储删除失败时仍保留存储账目。达到限额允许移除截图后提交文字，不自动删除合法旧反馈。
3. 旧封禁只保留不可逆摘要，无法恢复原地址；旧规则仍能识别原浏览器类别，新规则覆盖全部类别。
4. 当前飞书转发关闭，其既有转发后删除失败分支未验证；启用前需修复并复测。
5. 正式读者试用、人工精选标注与导读深度校准继续独立推进；技术回归不能代替研究结论的来源核对。
6. 本轮未作高流量攻击、全设备无障碍、第三方平台管理面或全历史内容逐篇审查，不能承诺网站不存在任何安全问题。
