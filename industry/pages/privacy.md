浏览本站无需注册。初版不接入访客统计、广告追踪和第三方推送。我们不出售访客资料。

## 1. 浏览器本地数据

收藏、已读记录、主题偏好和反馈草稿只保存在你当前的浏览器里，不会发送到服务器。清除浏览器数据后它们会消失；换设备不会同步。你可以在“收藏”页导出和导入这些数据。

## 2. 反馈

反馈内容、选填的邮箱、所附页面地址和截图会保存到服务器，用于排查问题和回复。请勿提交病历、处方、身份证件或其他不必要的敏感资料。为限流及防止滥用，系统保留从网络地址和浏览器类别计算的标识；该标识不直接保存原始网络地址。

数据库保存在 Supabase，反馈截图放在其私有文件存储中，仅通过有管理员权限的接口读取。反馈保留至处理或删除请求完成，不承诺自动按固定天数删除。用户可通过反馈页提出查询、更正或删除请求，并提供此前的反馈内容、时间或邮箱以便核实。

管理员登录使用会话 Cookie，用于保护后台权限。应用密钥不会发送给普通浏览者。

## 3. 服务器与网络日志

网站和 API 托管在 Render，数据库与原始上传文件托管在 Supabase，定时处理及备份通过 GitHub Actions 执行。默认尝试使用新加坡云区域；实际资源位置以上线配置为准。访问这些境外服务会产生网络传输。

托管方可能按其配置记录 IP 地址、访问时间、请求路径和设备信息；其保留期限和处理方式由服务商决定。应用任务日志用于故障排查，普通记录约保留 30 天，失败记录约 90 天；这些任务记录不是访客访问统计。公开代码仓库中不包含真实数据库、截图、账号密码或 API key。

模型用于处理公开信源内容，不因普通页面浏览而调用。初版不将访客反馈、联系邮箱或截图提交给大模型。所选模型服务商和接口由运营者在正式启用前确认；如后续变更数据用途，须更新本页。

数据库备份在应用侧加密后存入 Supabase 私有存储，只保留最新一份每日备份。删除反馈后，旧备份中可能暂时保留对应记录，待下一次成功备份覆盖；维护者不应通过恢复旧备份重新使用已经请求删除的资料。备份和数据库位于同一项目，不能保证在整个项目删除后仍可恢复。
